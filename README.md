# 🤖 AI-Based Spam Message Detector using Python

The **AI-Based Spam Message Detector** is a Python-based machine learning project that classifies messages as **Spam** or **Not Spam** using **Natural Language Processing (NLP)** and **Artificial Intelligence**.
It combines machine learning algorithms with a **Tkinter GUI** to offer real-time spam detection through an easy-to-use interface.

---

## 🧠 Description

This project demonstrates how AI can help detect spam messages efficiently. It analyzes message text, extracts linguistic features, and classifies it using models such as **Naïve Bayes** or **Logistic Regression**.

Messages are preprocessed through:

* Tokenization
* Stopword removal
* Lemmatization
* TF-IDF vectorization

The trained model can accurately identify spam patterns in SMS or text messages. The **GUI** provides users a simple interface to input any message and instantly see whether it’s *Spam* or *Not Spam*.

---

## ✨ Features

* 🔹 **Real-Time Classification** – Detect spam messages instantly.

## ⚙️ Installation & Setup

1. **Clone the Repository**

   ```bash
   git clone https://github.com/yourusername/ai-spam-detector.git
   cd ai-spam-detector
   ```

2. **Install Dependencies**

   ```bash
   pip install -r requirements.txt
   ```

3. **Run the Application**

   ```bash
   python main.py
   ```

4. **Enter any message** in the GUI input box to classify it as *Spam* or *Not Spam*.

---

## 🧩 How It Works

1. **Data Preprocessing:** The dataset is cleaned, tokenized, and vectorized using TF-IDF.
2. **Model Training:** A supervised ML model learns from labeled SMS data.
3. **Prediction:** The trained model predicts incoming messages as spam or not spam.
4. **Visualization:** Tkinter displays results with color-coded labels for clarity.
